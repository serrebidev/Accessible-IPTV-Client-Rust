# 05: Owner-heard accessibility gate

**What to build:** Validate the complete local playlist-browse slice with the blind product owner using NVDA and keyboard interaction, and record the manual evidence separately from automated test results.

**Blocked by:** 04: Playlist recovery and parity evidence

**Status:** ready-for-agent

- [ ] The owner can open a local playlist using keyboard-only interaction.
- [ ] NVDA announces the playlist control, channel list, channel rows, search control, result changes, and recovery states clearly.
- [ ] Focus order and focus restoration remain usable through load, search, clear, no-result, and recovery flows.
- [ ] Large-list browsing and search remain practically responsive during the hands-on pass.
- [ ] Any failed manual criterion has a reproducible note and follow-up ticket instead of being hidden by automated results.
- [ ] The manual result is recorded as a separate owner-heard acceptance record.
