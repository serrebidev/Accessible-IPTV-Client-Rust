# Credits

This is the Rust port of [Accessible IPTV Client](https://github.com/serrebidev/Accessible-IPTV-Client). The Python app remains the shipping product while this port reaches feature parity.

Third-party projects it uses:

- libVLC for the built-in player (bundled in release packages, loaded at runtime).
- wxDragon (wxWidgets) for the desktop interface.
- ship-shape for the verified updater and minisign signature checks.

Questions and bug reports are welcome in the [SerrebiProjects Telegram group](https://t.me/SerrebiProjects). More serrebi projects: [projects.serrebiradio.com](https://projects.serrebiradio.com).
