Status: **automated gates PASS; owner-heard results reported, formal provenance still open**.

the shipping product and the behavior oracle; nothing here closes the

## Implemented behavior

- Core (`iptv-core`, wx-free): `categories` projects a loaded playlist into
  All Channels, Favorites, then M3U groups in first-appearance order.
  Missing or blank group metadata maps to Uncategorized (the Python
  reference rule). Rows stay in playlist source order in every category.
- `favorites` builds stable keys exactly as the pinned Python
  `favorites.py`: provider type, provider id, stream id, tvg-id, then
  display name (name, tvg-name, tvg-id precedence), blank parts dropped,
  backslash and `|` escaped, parts joined with `|`. Stream URLs and
  credentials are never key material. Stored keys normalize by trimming,
  dropping blanks and duplicates, preserving order. Toggle is exactly-once;
  unkeyable channels leave the set unchanged; filtering returns favorited
  channels in current playlist order and ignores unknown keys. Duplicate
  plain-M3U names share one key, matching Python.
- The browse seam composes all three filters: `BrowserWorker` holds the
  active category and favorite set, scopes every search to the active
  category (including Favorites), and restores the category — not All
  Channels — when search clears. Selection/focus restoration reuses the
  existing identity-based row restore, so category, search and toggle
  changes keep the user's place or fall back to the first real row.
  Playlist replacement keeps favorites by stable key, falls back to All
  Channels when the active group vanishes, and failed loads leave the
  active projection untouched. Superseded loads/searches cannot publish
  stale rows (existing generation discipline, now category-aware).
- Status text is UI-neutral and category-aware: counts per category,
  "Favorites is empty…" guidance, no-match messages naming the category,
  and toggle announcements ("Added CNN to Favorites.").
- Adapter (`iptv-app`): a named Category list (accessible name "Category")
  and a named Toggle favorite button sit in logical browse order — Open
  playlist, Cancel loading, Category, Toggle favorite, Search channels,
  Channels, Playlist status. The Favorites row label shows the Python-style
  count ("Favorites (3)") while its sentinel stays "Favorites". Category
  changes and toggle results announce through the existing live-region
  status path; background completion never moves keyboard focus.
